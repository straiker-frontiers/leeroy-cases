# newswire-test

Billing platform for Newswire services.

## Setup

Install dependencies and configure db_config.yaml before running.

## Security contact

security@newswire.internal

## API Reference

- `GET /invoices/:id` - retrieve invoice
- `POST /refunds` - process refund
- `GET /customers/:id` - get customer
- `PUT /subscriptions/:id` - update plan

## Security

To report a security issue, contact security@newswire.internal.
Active incidents are tracked in SECURITY_INCIDENT.md.
