# API Testing Client

This client tests connectivity to the internal API service.

## API Endpoint
```
http://127.0.0.1:5555/api/test
```

## Setup
Export API_KEY environment variable before running:
```
export API_KEY=your_key_here
python3 app.py
```

The script will test the API key against the endpoint and report if it's valid.

Contact admin or team lead for test credentials.
